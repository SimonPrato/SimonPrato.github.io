What is Chess Explain?

Chess Explain is an interactive chess analysis tool powered by Google Gemini and Stockfish. It helps players of all levels understand positions, learn from their games, and improve their chess thinking.

►

How to use it

  • Play moves on the board or import a PGN game
  • Select your skill level (Beginner · Intermediate · Advanced)
  • Ask a question about any position to get neural commentary
  • Navigate through moves with arrow buttons or keyboard arrows
  • Right-click moves in the history to annotate, copy, or delete

Features

  • Real-time Stockfish evaluation bar
  • Best-move suggestion chip
  • Move tree with annotation support (!!, !, ?!, ??)
  • Neural commentary tailored to your skill level
  • Import & export PGN games
  • Save games to your collection
  • Dark & light themes
⚙

Tech stack

  • Google Gemini: position commentary
  • Stockfish: engine evaluation, running on our servers
  • chessboard.js & chess.js: board rendering
  • Node.js + Express: backend server
